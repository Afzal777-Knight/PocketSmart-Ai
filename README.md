# PocketSmart AI

PocketSmart AI is an intelligent, budget-aware recommendation platform designed to help users make smarter decisions based on their budget, preferences, and requirements.

The application provides personalized recommendations for:
- 🏠 Home planning
- 🎉 Party planning
- 💎 Jewelry selection

Built with FastAPI, Python, SQLite, Jinja2, and AI-powered recommendation features, PocketSmart AI combines practical budgeting with personalized suggestions in a simple web interface
